# 发布范围与复查记录

[English](publication_en.md) | [简体中文](publication.md)

本仓库从新目录和独立 Git 开始，没有迁移原仓库提交历史，也不关联私有备份仓库。当前公开代码选取包括 React 前端、FastAPI 工作台、检索与 Agent 核心、CLI 样例和独立的 Streamlit 无密钥小样例。

公开内容用于代码阅读和面试交流，不代表完整部署包。完整规范库、客户方案、原件、账号数据库和服务凭据由使用者自行准备；没有这些外部资源时，主 Web 工作台不能完成对应的真实资料核查。现有三张截图来自首次发布的 Streamlit 页面，不是当前 React 界面。CLI 与 Streamlit 小样例使用自编虚构材料。

未随仓库发布的内容包括原项目配置、完整标准资料、第三方数据集原文、真实方案及客户附件、私人评测输入、运行日志、向量缓存、模型权重、认证数据库、附件与历史记录、备份压缩包和旧 Git 对象。

发布树检查脚本为 python scripts/verify_public_tree.py，也支持 --tracked 检查 Git 索引中的文件。规则扫描只能覆盖已配置的敏感文件类型、个人路径与凭据格式，不能替代对新增文件和截图的人工复核，也不能确认公司协议、课程许可或版权归属。课程来源与第三方许可边界见[第三方说明](../THIRD_PARTY_NOTICES.md)。

样例中的 DEMO 标准号、阈值、对象和方案均为自编虚构，不引用或代替实际工程规范。公开的历史评测只有汇总数值；原始题目、参考答案、方案、全文报告和请求记录未公开，仓库样例不复现评测结果。
