# 发布范围与复查记录

本演示版采用全新目录、全新 Git 初始化和首次提交。只选取核心源码及其本地依赖，不使用 clone、fork、bundle、旧提交 cherry-pick 或旧对象库；新仓库与任何私有备份仓库独立。

公开文件：核心源码、演示入口、配置占位模板、依赖声明、自编资料与方案、生成的自编样例报告、演示截图、评测数值摘要及说明。

排除文件：原 `.env`、完整规范库、第三方数据集全文、真实方案和客户附件、个人简历、原截图、日志、向量缓存、模型权重、数据库、运行目录、备份压缩包、旧 Git 历史与远程配置。

复查工具：`python scripts/verify_public_tree.py` 扫描待发布树；`python scripts/verify_public_tree.py --tracked` 扫描 Git 索引中的文件，检测敏感文件类型、个人绝对路径、已知凭据格式和私钥头，并拒绝符号链接。报告只输出文件位置和问题类别，避免再次显示疑似密钥。

自动扫描只能发现其规则覆盖的问题，不能确认公司协议、课程许可或著作权归属。发布者应确认选取核心代码的公开权；本项目代码采用 MIT 许可证；本仓库保留课程来源说明，第三方依赖仍遵循各自许可证。

演示资料中的 DEMO 标准号、阈值、对象和方案均为自编虚构；不引用或代替实际工程规范。已有评测只发布汇总数值，原始题目、参考答案、方案、全文报告和请求记录未公开。
