## Boundaries retained

- OCR is disabled by default. Its current adapter uses the documented ordinary Alibaba Cloud endpoint and fixed OCR model; credentials and materials are supplied by the operator. Recognized text remains unverified.
- Interrupted tasks are isolated only after confirming the local worker and registered resources have exited. External request completion remains unknown and no automatic retry is added.
- Corpus mmap opening no longer compares the source directory. Operators manage source/index versions and rebuild matching packages; structural validation remains.
- Private history, real corpora/plans, database contents, OCR caches, service credentials and deployment identities are excluded. This snapshot is submitted through a PR and is not automatically merged.
